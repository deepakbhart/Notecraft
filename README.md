# Notecraft
This is a simple website project to create and order a customise notes 
NoteCraft is a web-based platform designed to help students generate customized study notes based on their academic needs, available study time, weak topics, and syllabus. The system provides two major services:

System-generated PDF notes (short, medium, or full length).

Student-requested handwritten-style notes delivered through an admin-managed backend.

NoteCraft reduces the time students spend searching, preparing, or organizing study material. It offers an easy, fast, and personalized learning experience for college students and competitive exam aspirants.
